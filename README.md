# CAN-Based Automotive Dashboard using PIC18F4580

This project demonstrates a CAN-based automotive dashboard developed using Embedded C and PIC18F4580 microcontrollers.

## Project Architecture

- ECU1 – Sensor/Input Unit
- ECU2 – Processing/Control Unit
- ECU3 – Dashboard Display Unit

## Features

- CAN Communication
- Real-Time Vehicle Monitoring
- RPM Display
- Speed Display
- Temperature Monitoring
- Embedded C Firmware Development

## Technologies Used

- Embedded C
- PIC18F4580
- CAN Protocol
- UART
- MPLAB X IDE
